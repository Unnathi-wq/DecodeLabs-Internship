Console To-Do List Application
A simple, interactive command-line to-do list manager built with Python. This project allows users to add tasks, view their active task list, and exit the program using an interactive menu.

Features
Add tasks dynamically to your list

View tasks both as a raw list and as an indexed, numbered list

Interactive loop that keeps the program running until you choose to quit

Scoped inputs so prompts only appear for the selected action

Prerequisites
Python 3.x installed on your computer

How to Run
Open your terminal or command prompt.

Navigate to the project folder:
cd your-project-folder

Run the script:
python your_file_name.py
